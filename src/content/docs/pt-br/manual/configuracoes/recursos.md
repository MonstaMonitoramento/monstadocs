Neste local é possível personalizar todos dados relacionados a configuração do Monsta e também a restauração de backups do banco de dados.

![image.png](/src/assets/images/ms62iuxs-toox2jdq.png)


| Opção | Descrição |
| -------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ![image-1647434370176.png](/src/assets/images/p60_image-1647434370176.png) | **Modo noturno**: Quando ativado, inverte as cores de tela do Monsta. |
| ![image-1647435194179.png](/src/assets/images/p60_image-1647435194179.png) | **Templates**: Permite criar, editar e remover templates e monitores existentes. Para mais informações consulte: [Templates](/pt-br/manual/configuracoes/templates). |
| ![image-1647435290317.png](/src/assets/images/p60_image-1647435290317.png) | **Agentes**: Permite personalizar configurações dos agentes e bloqueá-los. Para mais informações consulte: [Agentes](/pt-br/manual/configuracoes/agentes). |
| ![image-1647435557586.png](/src/assets/images/p60_image-1647435557586.png) | **Grupos de Dispositivos**: Permite adicionar e remover grupos de dispositivos bem como gerenciá-los. Para mais informações consulte: [Grupo de Dispositivos](/pt-br/manual/configuracoes/grupo-de-dispositivos). |
| ![image-1647435611989.png](/src/assets/images/p60_image-1647435611989.png) | **Monsta Studio**: Permite criar, editar e remover as fontes de dados, buscas de instâncias, métodos de uptime e ações. Para mais informações consulte: [Monsta Studio](/pt-br/manual/configuracoes/monsta-studio). |
| ![image-1647435653352.png](/src/assets/images/p60_image-1647435653352.png) | **Imagens**: Gerencia a biblioteca de imagens do Monsta. Para mais informações consulte: [Imagens](/pt-br/manual/configuracoes/imagens). |
| ![image-1739982775972.png](/src/assets/images/p60_image-1739982775972.png) | **Sons**: É a biblioteca de sons do Monsta onde é feito o gerenciamento dos arquivos que estarão disponíveis para os alertas. Para mais informações consulte: [Sons](/pt-br/manual/configuracoes/sons). |
| ![image-1647435745876.png](/src/assets/images/p60_image-1647435745876.png) | **Atualização**: Alterna entre os canais de atualização do Monsta. Podem ser escolhidos os canais: - **Oficial**: Canal com atualizações consideradas estáveis. - **Beta**: Canal com atualizações em fase de testes. |
| ![image-1647436547485.png](/src/assets/images/p60_image-1647436547485.png) | **Usuários**: Gerencia os usuários no Monsta. Para mais informações consulte: [Usuários](/pt-br/manual/configuracoes/usuarios). |
| ![image-1647436903151.png](/src/assets/images/p60_image-1647436903151.png) | **Parâmetros**: Permite alterar os parâmetros de configuração geral do Monsta. Cuidado: Parâmetros configurados de forma incorreta podem tornar o Monsta inoperante. Para mais informações consulte: [Parâmetros](/pt-br/manual/configuracoes/parametros). |
| ![image-1647437280055.png](/src/assets/images/p60_image-1647437280055.png) | **Plugins**: Permite ativar ou desativar recursos disponíveis no Monsta. Para mais informações consulte: [Plugins](/pt-br/manual/configuracoes/plugins). |
| ![image-1756129051901.png](/src/assets/images/p60_image-1756129051901.png) | **Serviços**: Nessa opção é possível visualizar o status dos serviços do Monsta e, se necessário, reiniciá-los individualmente. Para mais informações consulte: [Serviços](/pt-br/manual/configuracoes/servicos). |
| ![image-1647435477277.png](/src/assets/images/p60_image-1647435477277.png) | **Backup em Nuvem**: Nesta opção é possível restaurar um backup das configurações do Monsta. Para mais informações consulte: [Backup em Nuvem](/pt-br/manual/configuracoes/backup-em-nuvem). |
| ![image-1739983055127.png](/src/assets/images/p60_image-1739983055127.png) | **Certificado TLS**: Instale e gerencie seus certificados para acessar a interface web do Monsta. É possível utilizar certificados próprios, gerados pelo Monsta ou automatizá-los através do Letsencrypt. Para mais informações consulte: [Certificado TLS](/pt-br/manual/configuracoes/certificado-tls). |
| ![image-1647437341171.png](/src/assets/images/p60_image-1647437341171.png) | **Chave de Licença**: Apresenta informações sobre a chave de licença utilizada. Para mais informações consulte: [Chave de Licença](/pt-br/manual/configuracoes/chave-de-licenca). |
| ![image.png](/src/assets/images/ms62pllf-fv4wytcc.png) | **Insights**: O Monsta envia automaticamente um resumo mensal por e-mail no início de cada mês, trazendo insights essenciais sobre o desempenho e o status do sistema. |
| ![image-1647437392464.png](/src/assets/images/p60_image-1647437392464.png) | **Sobre o Monsta**: Apresenta informações sobre a versão atual. |
