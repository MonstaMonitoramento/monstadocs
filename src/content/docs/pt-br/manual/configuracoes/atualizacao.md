Mantenha seu software sempre atualizado com a versão mais recente e aproveite os novos recursos, melhorias de desempenho e correções de bugs.

![image.png](/src/assets/images/ms61n9ly-nv0wlu2k.png)


| Opção | Descrição |
| ------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ![image.png](/src/assets/images/ms61obm6-w7qjs55l.png) | Oferecemos dois canais de atualização para você escolher: • **Oficial**: Este canal é recomendado para a maioria dos usuários. Ele oferece atualizações testadas e aprovadas, garantindo a estabilidade e segurança do software. • **Beta**: Este canal é para usuários que desejam experimentar os recursos mais recentes em primeira mão. As atualizações beta podem conter novos recursos e melhorias, mas também podem apresentar alguns bugs ou instabilidades. |
| ![image.png](/src/assets/images/ms61ph12-c3e44bad.png) | **Horário de Verificação**: O Monsta permite que você defina um horário específico para a verificação e aplicação automática de atualizações diárias. Essa funcionalidade garante que o processo ocorra em momentos de menor impacto na operação da sua rede. |
| ![image.png](/src/assets/images/ms61znje-qrizj4u3.png) | **Verificação Manual**: Além do agendamento automático, você pode executar uma checagem de novas versões de forma imediata a qualquer momento.Ao clicar neste botão, o Monsta consulta instantaneamente os servidores de atualização para verificar a disponibilidade de novas versões, ignorando temporariamente o agendamento diário configurado.**Comportamento:** Caso haja uma versão mais recente disponível, o sistema perguntará se você deseja realizar a atualização. Se já estiver na versão mais recente, uma mensagem informará que o sistema está atualizado. |
| ![image.png](/src/assets/images/ms6256ha-tthpw4wg.png) | **Histórico de Alterações (Changelog)**: Para acompanhar as novidades, correções e melhorias implementadas em cada versão do sistema, você pode consultar o changelog oficial a qualquer momento diretamente pela interface. Essas informações também estão disponívels no site [https://docs.monsta.com.br/pt-br/tech/changelog/changelogs-monsta/](https://docs.monsta.com.br/pt-br/tech/changelog/changelogs-monsta/) |


:::note[Preservação de Configurações]
As atualizações do Monsta são projetadas para manter a integridade das configurações existentes. Parâmetros customizados nos monitores — incluindo frequência de coleta (intervalo), número de tentativas (retries) e limites de alerta (thresholds) — não sofrem alterações durante o processo de atualização da plataforma.
:::
