## O que é uma API?

Uma **API** (*Application Programming Interface*, ou Interface de Programação de Aplicações) funciona como uma "ponte" que permite que dois *softwares* diferentes se comuniquem e troquem informações de maneira segura e controlada.

Em termos práticos, uma API permite que:

- Sistemas externos consultem dados do Monsta: Por exemplo, exibir informações do Monsta em um painel de controle (*dashboard*) customizado ou em um software de BI.
- Sistemas externos enviem comandos ao Monsta: Por exemplo, automatizar a criação de dispositivos.

## O Monsta possui uma API disponível?

**Atualmente, o Monsta não oferece suporte a uma API pública para integrações externas.**

Entendemos que a capacidade de conectar sistemas é fundamental para escalar operações e aumentar a produtividade. Por isso, esta funcionalidade já está no planejamento do nosso time de desenvolvimento.

### Roadmap de Desenvolvimento

A implementação de uma API robusta, segura e escalável já consta em nosso Roadmap de Desenvolvimento.

O planejamento é que essa funcionalidade seja entregue a partir da **versão 7** do Monsta. Nosso objetivo é garantir que a futura interface de integração ofereça toda a estabilidade e segurança que os nossos usuários esperam da nossa plataforma.

:::tip

Enquanto a funcionalidade não é lançada, recomendamos que acompanhe nosso *[changelog](/pt-br/tech/changelog/changelogs-monsta)* para saber das atualizações e novidades.

:::
