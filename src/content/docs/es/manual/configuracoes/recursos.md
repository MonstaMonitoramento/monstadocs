En este lugar es posible personalizar todos los datos relacionados con la configuración de Monsta y también la restauración de copias de seguridad de la base de datos.

![image.png](/src/assets/images/ms62iuxs-toox2jdq.png)


| Opción | Descripción |
| -------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ![image-1647434370176.png](/src/assets/images/p60_image-1647434370176.png) | **Modo nocturno**: Al activarlo, invierte los colores de la pantalla de Monsta. |
| ![image-1647435194179.png](/src/assets/images/p60_image-1647435194179.png) | **Plantillas**: Permite crear, editar y eliminar plantillas y monitores existentes. Para más información consulte: [Templates](/es/manual/configuracoes/templates). |
| ![image-1647435290317.png](/src/assets/images/p60_image-1647435290317.png) | **Agentes**: Permite personalizar configuraciones de los agentes y bloquearlos. Para más información consulte: [Agentes](/es/manual/configuracoes/agentes). |
| ![image-1647435557586.png](/src/assets/images/p60_image-1647435557586.png) | **Grupos de Dispositivos**: Permite añadir y eliminar grupos de dispositivos así como gestionarlos. Para más información consulte: [Grupo de Dispositivos](/es/manual/configuracoes/grupo-de-dispositivos). |
| ![image-1647435611989.png](/src/assets/images/p60_image-1647435611989.png) | **Monsta Studio**: Permite crear, editar y eliminar las fuentes de datos, búsquedas de instancias, métodos de uptime y acciones. Para más información consulte: [Monsta Studio](/es/manual/configuracoes/monsta-studio). |
| ![image-1647435653352.png](/src/assets/images/p60_image-1647435653352.png) | **Imágenes**: Gestiona la biblioteca de imágenes de Monsta. Para más información consulte: [Imágenes](/es/manual/configuracoes/imagens). |
| ![image-1739982775972.png](/src/assets/images/p60_image-1739982775972.png) | **Sonidos**: Es la biblioteca de sonidos de Monsta donde se gestiona los archivos que estarán disponibles para las alertas. Para más información consulte: [Sons](/es/manual/configuracoes/sons). |
| ![image-1647435745876.png](/src/assets/images/p60_image-1647435745876.png) | **Actualización**: Alterna entre los canales de actualización de Monsta. Se pueden elegir los canales: - **Oficial**: Canal con actualizaciones consideradas estables. - **Beta**: Canal con actualizaciones en fase de pruebas. |
| ![image-1647436547485.png](/src/assets/images/p60_image-1647436547485.png) | **Usuarios**: Gestiona los usuarios en Monsta. Para más información consulte: [Usuários](/es/manual/configuracoes/usuarios). |
| ![image-1647436903151.png](/src/assets/images/p60_image-1647436903151.png) | **Parámetros**: Permite cambiar los parámetros de configuración general de Monsta. Cuidado: Parámetros configurados de forma incorrecta pueden dejar Monsta inoperativo. Para más información consulte: [Parámetros](/es/manual/configuracoes/parametros). |
| ![image-1647437280055.png](/src/assets/images/p60_image-1647437280055.png) | **Plugins**: Permite activar o desactivar características disponibles en Monsta. Para más información consulte: [Plugins](/es/manual/configuracoes/plugins). |
| ![image-1756129051901.png](/src/assets/images/p60_image-1756129051901.png) | **Servicios**: En esta opción es posible visualizar el estado de los servicios de Monsta y, si es necesario, reiniciarlos individualmente. Para más información consulte: [Serviços](/es/manual/configuracoes/servicos). |
| ![image-1647435477277.png](/src/assets/images/p60_image-1647435477277.png) | **Copia de seguridad en la nube**: En esta opción es posible restaurar una copia de seguridad de las configuraciones de Monsta. Para más información consulte: [Backup em Nuvem](/es/manual/configuracoes/backup-em-nuvem). |
| ![image-1739983055127.png](/src/assets/images/p60_image-1739983055127.png) | **Certificado TLS**: Instale y gestione sus certificados para acceder a la interfaz web de Monsta. Es posible usar certificados propios, generados por Monsta o automatizarlos mediante Letsencrypt. Para más información consulte: [Certificado TLS](/es/manual/configuracoes/certificado-tls). |
| ![image-1647437341171.png](/src/assets/images/p60_image-1647437341171.png) | **Clave de licencia**: Presenta información sobre la clave de licencia utilizada. Para más información consulte: [Chave de Licença](/es/manual/configuracoes/chave-de-licenca). |
| ![image.png](/src/assets/images/ms62pllf-fv4wytcc.png) | **Insights**: Monsta envía automáticamente un resumen mensual por correo electrónico al inicio de cada mes, ofreciendo insights esenciales sobre el rendimiento y el estado del sistema. |
| ![image-1647437392464.png](/src/assets/images/p60_image-1647437392464.png) | **Acerca de Monsta**: Presenta información sobre la versión actual. |
