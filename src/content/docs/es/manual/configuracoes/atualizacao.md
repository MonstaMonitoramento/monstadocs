Mantenga su software siempre actualizado con la versión más reciente y aproveche las nuevas funciones, mejoras de rendimiento y correcciones de errores.

![image.png](/src/assets/images/ms61n9ly-nv0wlu2k.png)


| Opção | Descrição |
| ------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ![image.png](/src/assets/images/ms61obm6-w7qjs55l.png) | Ofrecemos dos canales de actualización para que elija:<br />• **Oficial**: Este canal está recomendado para la mayoría de los usuarios. Ofrece actualizaciones probadas y aprobadas, garantizando la estabilidad y seguridad del software.<br />• **Beta**: Este canal es para usuarios que desean probar las funciones más recientes de primera mano. Las actualizaciones beta pueden incluir nuevas funciones y mejoras, pero también pueden presentar algunos errores o inestabilidades. |
| ![image.png](/src/assets/images/ms61ph12-c3e44bad.png) | **Horario de Verificación**: Monsta le permite establecer una hora específica para la comprobación y aplicación automática de actualizaciones diarias. Esta funcionalidad garantiza que el proceso ocurra en momentos de menor impacto en la operación de su red. |
| ![image.png](/src/assets/images/ms61znje-qrizj4u3.png) | **Verificación Manual**: Además de la programación automática, puede ejecutar una comprobación de nuevas versiones de forma inmediata en cualquier momento.<br />• Al hacer clic en este botón, Monsta consulta instantáneamente los servidores de actualización para verificar la disponibilidad de nuevas versiones, ignorando temporalmente la programación diaria configurada.<br />• **Comportamiento**: En caso de que haya una versión más reciente disponible, el sistema preguntará si desea realizar la actualización. Si ya está en la versión más reciente, un mensaje informará que el sistema está actualizado. |
| ![image.png](/src/assets/images/ms6256ha-tthpw4wg.png) | **Historial de cambios (*Changelog*)**: Para seguir las novedades, correcciones y mejoras implementadas en cada versión del sistema, puede consultar el *changelog* oficial en cualquier momento directamente desde la interfaz. Esta información también está disponible en *[Changelogs](/es/tech/changelog/changelogs-monsta)*. |


:::note[Preservación de la configuración]
Las actualizaciones de Monsta están diseñadas para mantener la integridad de las configuraciones existentes. Los parámetros personalizados en los monitores —incluida la frecuencia de recolección (intervalo), el número de intentos (*retries*) y los límites de alerta (*thresholds*)— no se modifican durante el proceso de actualización de la plataforma.
:::
