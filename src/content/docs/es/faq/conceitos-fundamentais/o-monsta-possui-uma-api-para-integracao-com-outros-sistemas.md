## ¿Qué es una API?

Una **API** (*Application Programming Interface*, o Interfaz de Programación de Aplicaciones) funciona como un "puente" que permite que dos *softwares* diferentes se comuniquen y compartan información de manera segura y controlada.

En términos prácticos, una API permite que:

- Sistemas externos consulten datos de Monsta: Por ejemplo, mostrar información de Monsta en un panel de control (*dashboard*) personalizado o en un software de BI.
- Sistemas externos envíen comandos a Monsta: Por ejemplo, automatizar la creación de dispositivos.

## ¿Monsta dispone de una API disponible?

**Actualmente, Monsta no ofrece soporte para una API pública para integraciones externas.**

Entendemos que la capacidad de conectar sistemas es fundamental para escalar operaciones y aumentar la productividad. Por eso, esta funcionalidad ya está en la planificación de nuestro equipo de desarrollo.

### Hoja de ruta de desarrollo

La implementación de una API robusta, segura y escalable ya figura en nuestra hoja de ruta de desarrollo.

La planificación es que esta funcionalidad se entregue a partir de la **versión 7** de Monsta. Nuestro objetivo es garantizar que la futura interfaz de integración ofrezca toda la estabilidad y seguridad que nuestros usuarios esperan de nuestra plataforma.

:::tip

Mientras la funcionalidad no se lance, recomendamos que consulte nuestro *[changelog](/es/tech/changelog/changelogs-monsta)* para conocer las actualizaciones y novedades.
