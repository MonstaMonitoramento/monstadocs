Keep your software always up to date with the latest version and take advantage of new features, performance improvements, and bug fixes.

![image.png](/src/assets/images/ms61n9ly-nv0wlu2k.png)


| Option | Description |
| ------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ![image.png](/src/assets/images/ms61obm6-w7qjs55l.png) | We offer two update channels for you to choose from:<br />• **Official**: This channel is recommended for most users. It provides tested and approved updates, ensuring the stability and security of the software.<br />• **Beta**: This channel is for users who want to try the latest features first-hand. Beta updates may include new features and improvements, but they can also present some bugs or instabilities. |
| ![image.png](/src/assets/images/ms61ph12-c3e44bad.png) | **Check Schedule**: Monsta allows you to set a specific time for the automatic daily checking and application of updates. This feature ensures the process runs at times of minimal impact on your network operation. |
| ![image.png](/src/assets/images/ms61znje-qrizj4u3.png) | **Manual Check**: In addition to automatic scheduling, you can perform an immediate check for new versions at any time.<br />• By clicking this button, Monsta instantly queries the update servers to check for the availability of new versions, temporarily bypassing the configured daily schedule.<br />• **Behavior**: If a newer version is available, the system will ask whether you want to perform the update. If you are already on the latest version, a message will inform you that the system is up to date. |
| ![image.png](/src/assets/images/ms6256ha-tthpw4wg.png) | **Change History (*Changelog*)**: To follow the news, fixes, and improvements implemented in each system version, you can consult the official changelog at any time directly from the interface. This information is also available at *[Changelogs](/en/tech/changelog/changelogs-monsta)*. |


:::note[Preservation of Settings]
Monsta updates are designed to maintain the integrity of existing settings. Custom parameters on monitors — including collection frequency (interval), number of attempts (*retries*) and alert thresholds (*thresholds*) — are not changed during the platform update process.
:::
