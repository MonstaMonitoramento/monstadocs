Here you can customize all data related to the Monsta configuration and also restore database backups.

![image.png](/src/assets/images/ms62iuxs-toox2jdq.png)


| Opção | Descrição |
| -------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ![image-1647434370176.png](/src/assets/images/p60_image-1647434370176.png) | **Night mode**: When enabled, inverts Monsta's screen colors. |
| ![image-1647435194179.png](/src/assets/images/p60_image-1647435194179.png) | **Templates**: Allows creating, editing and removing existing templates and monitors. For more information see: [Templates](/en/manual/configuracoes/templates). |
| ![image-1647435290317.png](/src/assets/images/p60_image-1647435290317.png) | **Agents**: Allows customizing agent settings and blocking them. For more information see: [Agents](/en/manual/configuracoes/agentes). |
| ![image-1647435557586.png](/src/assets/images/p60_image-1647435557586.png) | **Device Groups**: Allows adding and removing device groups as well as managing them. For more information see: [Device Groups](/en/manual/configuracoes/grupo-de-dispositivos). |
| ![image-1647435611989.png](/src/assets/images/p60_image-1647435611989.png) | **Monsta Studio**: Allows creating, editing and removing data sources, instance searches, uptime methods and actions. For more information see: [Monsta Studio](/en/manual/configuracoes/monsta-studio). |
| ![image-1647435653352.png](/src/assets/images/p60_image-1647435653352.png) | **Images**: Manages the Monsta image library. For more information see: [Images](/en/manual/configuracoes/imagens). |
| ![image-1739982775972.png](/src/assets/images/p60_image-1739982775972.png) | **Sounds**: The Monsta sound library where files available for alerts are managed. For more information see: [Sounds](/en/manual/configuracoes/sons). |
| ![image-1647435745876.png](/src/assets/images/p60_image-1647435745876.png) | **Update**: Switches between Monsta update channels. The following channels can be chosen: - **Official**: Channel with updates considered stable. - **Beta**: Channel with updates in testing. |
| ![image-1647436547485.png](/src/assets/images/p60_image-1647436547485.png) | **Users**: Manages users in Monsta. For more information see: [Users](/en/manual/configuracoes/usuarios). |
| ![image-1647436903151.png](/src/assets/images/p60_image-1647436903151.png) | **Parameters**: Allows changing general Monsta configuration parameters. Caution: Incorrectly configured parameters can render Monsta inoperative. For more information see: [Parameters](/en/manual/configuracoes/parametros). |
| ![image-1647437280055.png](/src/assets/images/p60_image-1647437280055.png) | **Plugins**: Allows enabling or disabling features available in Monsta. For more information see: [Plugins](/en/manual/configuracoes/plugins). |
| ![image-1756129051901.png](/src/assets/images/p60_image-1756129051901.png) | **Services**: In this option you can view the status of Monsta services and, if necessary, restart them individually. For more information see: [Services](/en/manual/configuracoes/servicos). |
| ![image-1647435477277.png](/src/assets/images/p60_image-1647435477277.png) | **Cloud Backup**: In this option you can restore a backup of Monsta configurations. For more information see: [Cloud Backup](/en/manual/configuracoes/backup-em-nuvem). |
| ![image-1739983055127.png](/src/assets/images/p60_image-1739983055127.png) | **TLS Certificate**: Install and manage your certificates to access Monsta's web interface. It is possible to use custom certificates, certificates generated by Monsta, or automate them through Letsencrypt. For more information see: [TLS Certificate](/en/manual/configuracoes/certificado-tls). |
| ![image-1647437341171.png](/src/assets/images/p60_image-1647437341171.png) | **License Key**: Displays information about the license key in use. For more information see: [License Key](/en/manual/configuracoes/chave-de-licenca). |
| ![image.png](/src/assets/images/ms62pllf-fv4wytcc.png) | **Insights**: Monsta automatically sends a monthly summary by email at the beginning of each month, providing essential insights about system performance and status. |
| ![image-1647437392464.png](/src/assets/images/p60_image-1647437392464.png) | **About Monsta**: Displays information about the current version. |
