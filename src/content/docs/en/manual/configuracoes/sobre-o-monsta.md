The **About Monsta** screen collects information about the installed system version and its identification. This information is useful for checking the version in use, identifying the installed build, and providing data during technical support requests or when validating updates.

![image.png](/src/assets/images/ms64weo6-bdoo5il5.png)

The following information is displayed on this screen:

- **Monsta Version**: Displays the installed system version, including the version number, the distribution channel (when applicable), and the build identifier.
- **Kernel Version**: Indicates the version of Monsta's internal kernel used by the installation.
- **Copyright information**: Displays the intellectual property details and the software development period.
