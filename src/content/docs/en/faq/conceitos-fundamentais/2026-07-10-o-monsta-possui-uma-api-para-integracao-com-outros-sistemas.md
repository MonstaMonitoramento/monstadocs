## What is an API?

An **API** (*Application Programming Interface*) works like a "bridge" that allows two different software applications to communicate and exchange information in a secure and controlled way.

In practical terms, an API allows:

- External systems to query data from Monsta: For example, display Monsta information in a custom control panel (*dashboard*) or in BI software.
- External systems to send commands to Monsta: For example, automate the creation of devices.

## Does Monsta have an API available?

**Currently, Monsta does not offer support for a public API for external integrations.**

We understand that the ability to connect systems is essential to scale operations and increase productivity. Therefore, this feature is already planned by our development team.

### Development Roadmap

The implementation of a robust, secure, and scalable API is already included in our Development Roadmap.

The plan is for this feature to be delivered starting in **version 7** of Monsta. Our goal is to ensure that the future integration interface provides all the stability and security our users expect from our platform.

:::tip

While the feature has not been released, we recommend that you follow our *[changelog](/en/tech/changelog/changelogs-monsta)* to learn about updates and what's new.

:::
