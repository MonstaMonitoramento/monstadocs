## What is an API?

An **API** (*Application Programming Interface*) functions as a "bridge" that allows two different *software* systems to communicate and exchange information in a secure and controlled way.

In practical terms, an API allows:

- External systems to query Monsta's data: For example, display Monsta information in a custom control panel (*dashboard*) or in BI software.
- External systems to send commands to Monsta: For example, automate device creation.

## Does Monsta have an API available?

**Currently, Monsta does not offer support for a public API for external integrations.**

We understand that the ability to connect systems is essential to scale operations and increase productivity. Therefore, this feature is already in our development team's planning.

### Development Roadmap

The implementation of a robust, secure, and scalable API is already included in our Development Roadmap.

The plan is for this feature to be delivered starting from **version 7** of Monsta. Our goal is to ensure that the future integration interface provides all the stability and security that our users expect from our platform.

:::tip

While the functionality is not yet released, we recommend that you follow our *[changelog](/en/tech/changelog/changelogs-monsta)* to learn about updates and news.

:::
